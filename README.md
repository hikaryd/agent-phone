# Agent Phone

Набор исходников и инструкций для **одного Android-телефона** с Chrome как браузером для агентов. Телефон запускает локальный ADB/CDP-мост в Termux; на сервере CDP доступен только через `127.0.0.1:19222`. Код не содержит привязки к модели телефона, конкретному владельцу, аккаунту или серверу.

## Структура

- `bridge/`: мост Termux, boot-скрипт и установка ограниченного SSH-доступа на VPS. Мост проверяет serial, восстанавливает ADB/CDP и поднимает обратный туннель.
- `adb-recovery/`: Android-помощник, наблюдатель Termux, сборка APK и boot-скрипт для восстановления беспроводной отладки на уже доверенной сети.
- `ssh-owner/`: отдельный SSH-доступ владельца к Termux через VPS.
- `owner-control/`: локальный контроль экрана, веб-панель Caddy и 15-минутный режим управления; агенту ключи и токены владельца не выдаются.
- `concurrency/`: необязательная очередь для клиентов с совместимым `browser-use` CLI; четыре фоновых чтения и эксклюзивные действия.
- `tab-cleaner/`: необязательная очистка страниц на сервере после 12 часов наблюдения.

## Границы

Android требует ручного сопряжения ADB, подтверждения новой Wi-Fi сети и разблокировки после перезагрузки. Помощник не обходит эти решения. CDP использует общий профиль Chrome с cookies и состоянием вкладок; агент получает доступ к нему после настройки серверного клиента. PIN и защищённые окна не обходятся. Пароль веб-панели действует независимо от 15-минутного режима; прямое VNC-соединение не ограничено сроком lease. Доверяйте пароль только владельцу. Если мост остановился, автоматическое выключение экрана по истечении режима не гарантируется. В проекте нет ключей, токенов, сертификатов, реальных IP-адресов или идентификаторов устройства.

Исходные скрипты рассчитаны на Termux и Linux VPS с OpenSSH/systemd. Порты `19222` (CDP), `19223` (SSH владельца), `8022` (Termux SSH) и `8443` (панель) закреплены на одну установку; проверьте отсутствие конфликтов перед запуском. Несколько телефонов на одном сервере требуют разных портов и отдельных пользователей.

## Локальная проверка

```sh
python3 -m unittest discover -s owner-control -p 'test_*.py'
python3 -m unittest discover -s bridge -p 'test_*.py'
python3 -m unittest discover -s adb-recovery -p 'test_*.py'
python3 -m compileall -q .
```

Эти проверки не подтверждают работоспособность Android, VPS, сертификата или браузера. Проверка на установленном телефоне описана в [OPERATIONS.md](OPERATIONS.md).
